How it works

  • 🎯Each question goes to one player. A right answer scores 1 point.
  • ⭐Know it without help? Type it in for a bonus star. Each star counts as an extra point.
  • 🔤Not sure? Open the 3 alternatives. But once they’re on screen, nobody can win a star on that question.
  • ➡️Wrong, or passed? The question goes to the next player, until someone gets it or everyone has tried. Then the next question starts with the next player.
  • ✂️Every wrong alternative is struck out. Once only one is left, it’s no secret, so the question ends there.
